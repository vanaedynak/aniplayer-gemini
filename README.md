# AniPlayer 🎬

Полноценный кроссплатформенный аниме-плеер для **Windows** и **iPad** с визуальным дизайном в стиле **Animix** (темная тема, неоновые акценты, карточки с соотношением 16:9, часы просмотра, карусели серий).

---

## 🌟 Ключевые возможности

* **Эстетика Animix Desktop**:
  * Фирменная глубокая темная палитра (`#0B0E14`), светящиеся градиентные акценты.
  * Панорамный Hero-баннер популярных релизов.
  * Блок «Недавно просмотренное» / «Продолжить просмотр» с бейджами оставшегося времени (например, `03:10`) и статусом `Просмотрено`.
  * Экран профиля с подробной аналитикой: часы просмотра, серии, круговая диаграмма и выбор светящихся рамок аватара.
  * Настройка масштабирования интерфейса (80% – 120%).
* **Продвинутый видеоплеер (AniLibria HLS)**:
  * Поддержка разрешения до 1080p FHD, смена скорости, громкости, полноэкранный режим.
  * **Умные опенинги и эндинги**: цветные маркеры на таймлайне; при старте опенинга всплывает кнопка «Смотреть опенинг» с 5-секундным обратным отсчетом (автопропуск, если не нажата). Автопереход на следующую серию при эндинге.
  * **Тач-жесты для iPad**: двойной тап по краям экрана для перемотки `±10 сек` (повторные тапы суммируются: `+20с`, `+30с`) с анимированным оверлеем и автозатуханием.
  * **Скрытие статус-бара**: системная строка состояния iPad скрывается в полноэкранном режиме.
  * Скриншот текущего кадра `📷` и режим «Картинка в картинке» `🗔`.
* **Мультиисточники**:
  * **AniLibria** (официальный v3 REST API и HLS-видео) — основной источник онгоингов, расписания и серий.
  * **YummyAnime** — альтернативные озвучки (Studio Band, AniDUB, Dream Cast и др.) через официальные открытые iframe-плееры.
  * **Shikimori** — метаданные, поиск и хронологическое дерево франшиз (основные сезоны с частями, фильмы, спешлы, спин-оффы).
* **Синхронизация и хранилище**:
  * Локальное хранилище истории, серий, списков и статистики.
  * Подготовленная архитектура для подключения Firebase Firestore.
* **Автообновление (Windows)**:
  * Проверка новых версий из GitHub Releases в фоне и кнопка «Обновить» в шапке.

---

## 🚀 Установка

* **Windows**: Скачайте `AniPlayer-Setup-*.exe` из [Releases](https://github.com/vanaedynak/aniplayer-gemini/releases).
* **iPad**: Скачайте `AniPlayer.ipa` из [Releases](https://github.com/vanaedynak/aniplayer-gemini/releases) и установите через TrollStore, AltStore или Sideloadly.

Подробная инструкция в [SETUP.md](./SETUP.md).
