# Спецификация архитектуры и дизайна AniPlayer

**Дата:** 30 октября 2026  
**Проект:** AniPlayer (Windows & iPad)  
**Дизайн-референс:** Animix Desktop UI/UX  

---

## 1. Обзор системы и цели

«AniPlayer» — кроссплатформенный аниме-плеер для Windows (десктоп на Electron с инсталлятором и автообновлением) и iPad (приложение на Capacitor с неподписанным `.ipa` для сайдлоада).

Ключевые визуальные и функциональные принципы:
- **Animix-эстетика**: глубокая темная тема (`#0B0E14`), фиолетово-сиреневые акцентные градиенты, полупрозрачные карточки со скруглением `rounded-2xl`, постеры с соотношением 16:9 и миниатюры эпизодов, бейджи остатка времени (`03:10`) или статуса `Просмотрено`.
- **HLS-плеер AniLibria**: собственный плеер с выбором качества (1080p / 720p / 480p), скоростью, горячими клавишами, оверлеем перемотки двойным тапом для iPad (`±10с`, суммирование повторных тапов), цветными метками опенингов/эндингов на таймлайне и 5-секундными кнопками-таймерами автопропуска.
- **Мультиисточники**: основной каталог и HLS-стриминг через открытый API AniLibria; альтернативные озвучки (включая Studio Band) через официальные встраиваемые iframe-плееры YummyAnime; метаданные, поиск и хронология франшиз через Shikimori.
- **Хронология франшиз**: структурированное дерево (основные сезоны, фильмы, OVA/спешлы, спин-оффы) с проверкой на Bleach (S1 366 эп. + S2 в 4 частях) и Naruto.
- **Синхронизация и локальное хранилище**: локальное хранилище с архитектурой, полностью готовой к подключению Firebase Firestore; история, таймкоды, списки и статистика.
- **Автоматизированная CI/CD сборка**: GitHub Actions собирает Windows installer (`.exe`) и iPad package (`.ipa`), публикуя релиз в GitHub Releases.

## 3. Пользовательский интерфейс в стиле Animix (Детальное описание экранов)

### 3.1. Палитра и стили
- **Фон приложения**: `#0B0E14` (основной холст), `#121620` (панели и карточки), `#1A202E` (активные элементы и ховер).
- **Акценты**:
  - Фиолетово-сиреневый градиент: `linear-gradient(135deg, #8B5CF6 0%, #6D28D9 100%)`.
  - Неоновые бейджи: `#A855F7`, свечения `box-shadow: 0 0 20px rgba(139, 92, 246, 0.35)`.
  - Текст: `#FFFFFF` (основной), `#94A3B8` (второстепенный), `#64748B` (неактивный).
  - Скругления: `rounded-2xl` (16px) для карточек и блоков, `rounded-full` для поисковой строки и кнопок действий.

### 3.2. Верхняя панель (Header)
- **Логотип**: стилизованный текст `animix` белого цвета со светящейся фиолетовой неоновой точкой над буквами `i` и `x`.
- **Поиск**: центрированная капсула с иконкой лупы, текстом-плейсхолдером `Быстрый поиск` и иконкой расширенных настроек `⊶`.
  - При вводе выпадает быстрый поиск: постер, русское и английское название, год, студия, бейдж `AniLibria` (если доступен в плеере).
- **Правый блок**:
  - Кнопка `★ Премиум` (градиент фиолетового, скругленная пилюля).
  - Колокольчик уведомлений (с красной точкой обновлений).
  - Аватар пользователя с настраиваемой светящейся рамкой (выбор рамки в профиле).
  - Кнопки управления окном для Windows: Свернуть `─`, Развернуть `▢`, Закрыть `✕`.

### 3.3. Левый сайдбар
- Навигационные пункты-кнопки (пилюли со скруглением):
  - `🏅 Лидерборд`
  - `📑 Категории / Каталог`
  - `📖 Манга BETA`
  - `💼 Моя коллекция`
- Информационный блок:
  - `Друзья в сети`: индикатор статуса ("Друзей в сети пока что нет").
  - `Тема сайта`: дропдаун тем ("Animix Dark", "Cyber Neon", "OLED Pure Black").
  - `Масштаб интерфейса`: ползунок / кнопки zoom (80% - 120%).

### 3.4. Главная страница (Home)
- **Hero-баннер**: широкий панорамный баннер топ-онгоинга (например, «Реинкарнация безработного») с градиентным затемнением слева направо, описанием и белой кнопкой `▶ Смотреть`.
- **Секция «Продолжить просмотр» / «Недавно просмотренное»**:
  - Горизонтальная сетка карточек с превью серий (16:9).
  - Бейдж в правом верхнем углу: таймкод остатка (напр. `03:10`) с полупрозрачным фоном либо бейдж `Просмотрено`.
  - Нижний оверлей карточки: номер серии и сезон («44 серия, 2 сезон») и жирное название аниме («Блич»).
- **Секция «Расписание онгоингов»**: вкладки по дням недели (Понедельник — Воскресенье) с карточками релизов AniLibria.

### 3.5. Экран просмотра и Плеер
- **Видеоплеер**:
  - 16:9 контейнер с кастомным минималистичным оверлеем управления:
    - Кнопки: Play/Pause, След. серия `⏭`, Громкость `🔊` с ползунком.
    - Временной индикатор: Текущее время `03:28` и время до конца `-21:04`.
    - Скраббер (полоса перемотки) с белым ползунком и цветными отметками опенинга (зеленоватый/синий отрезок) и эндинга (оранжевый/фиолетовый отрезок).
    - Кнопка «Смотреть опенинг» с обратным отсчетом 5 сек: появляется при входе в интервал опенинга. Если не нажата — автоскип.
    - Правые кнопки: Скриншот текущего кадра `📷`, Режим «Картинка в картинке» `🗔`, Настройки качества/скорости `⚙`, Полноэкранный режим `⛶`.
- **Жесты на iPad**:
  - Двойной тап по левой трети экрана: перемотка на -10 секунд.
  - Двойной тап по правой трети: перемотка на +10 секунд.
  - Повторные тапы суммируются: `+20с`, `+30с`.
  - Отображается всплывающий круг с анимацией волны и затуханием через 600 мс.
  - При переходе в полноэкранный режим системный статус-бар iPad скрывается.
- **Панель источников и озвучек под плеером**:
  - Аватар и название тайтла в пилюле.
  - Переключатели плееров: `AniLibria UHD`, `AnimixLite`, `Kodik RAW / YummyAnime (Studio Band)`.
  - Кнопки `Отключить рекламу`, `След. серия`.
- **Карусель серий и выбор сезонов**:
  - Пилюли фильтра: `Номер`, `Сезон 1`, `Сезон 2`, `Сезон 2 · Часть 2`.
  - Горизонтальная прокрутка миниатюр серий с подписями `Серия 1`, `Серия 2`...
- **Секция комментариев**: поле ввода, кнопка отправки, правила сообщества.
- **Секция франшизы**: визуальное дерево связанных произведений (Сезоны по порядку, Фильмы, OVA, Спин-оффы).

### 3.6. Профиль и статистика (как на скриншоте 4)
- Большой счетчик «Часов просмотра» (напр., `250.7`).
- Метрики: «Серий просмотрено» (752), «Часов за неделю» (1.3), «Друзей» (0).
- Круговая диаграмма (Donut chart): Просмотрено (зеленый), Брошено (красный), Отложено (желтый), В процессе (серый/синий), В планах (голубой).
- Витрина анимированных неоновых рамок для аватара с кнопкой переключения.

## 4. Источники контента и API-интеграции

### 4.1. AniLibria API (Основной)
- **Базовый URL**: `https://api.anilibria.tv/v3/`
- **Методы**:
  - `title/search?search={query}&filter=id,names,posters,player,genres,season,description`: поиск релизов.
  - `title/schedule`: расписание онгоингов по дням недели.
  - `title?id={id}` или `code={code}`: полная информация о релизе со списком серий и таймкодами опенингов/эндингов (`skips.opening`, `skips.ending`).
- **HLS-потоки**:
  - Хост стриминга: `https://cache.libria.fun` (или динамический `host` из ответа API).
  - Качество: `fhd` (1080p), `hd` (720p), `sd` (480p).

### 4.2. Shikimori API (Метаданные и Франшизы)
- **Базовый URL**: `https://shikimori.one/api/`
- **Заголовки**: `User-Agent: AniPlayer-Desktop-App`
- **Франшизы**: `GET /api/animes/{id}/franchise`
  - Возвращает граф узлов (`nodes`) и связей (`links`).
  - Алгоритм классификации:
    1. **Основные сезоны**: узлы с типом `tv`, фильтруемые по цепочке предков/потомков, упорядоченные по году выхода. Разделение на части по названиям («Part 2», «2 сезон 2 часть»).
    2. **Полнометражные фильмы**: тип `movie`.
    3. **OVA / Спешлы**: тип `ova`, `special`, `ona`.
    4. **Спин-оффы**: узлы с реляцией `spin_off` или ответвления от основного сюжета.
  - Проверка:
    - *Bleach*: 1 сезон (1-366 эп.), Тысячелетняя кровавая война (Season 2) Parts 1-4.
    - *Naruto*: Наруто (220 эп.) -> Наруто: Ураганные хроники (500 эп.) -> Боруто; фильмы и OVA отдельно.

### 4.3. YummyAnime API (Альтернативные озвучки и Studio Band)
- Поиск тайтлов по открытому API YummyAnime (`https://api.yummyanime.tv/` или агрегаторы открытых плееров).
- Получение официальных iframe-плееров с выбором озвучек (Studio Band, AniDUB, Dream Cast и др.) без нелегального скрейпинга защищенных видеопотоков.

## 5. Плеер и воспроизведение

### 5.1. Управление воспроизведением
- Клавиатурные шорткаты:
  - `Space` / `K`: Play / Pause.
  - `ArrowLeft` / `ArrowRight`: Перемотка на -5с / +5с.
  - `J` / `L`: Перемотка на -10с / +10с.
  - `ArrowUp` / `ArrowDown`: Громкость ±10%.
  - `M`: Mute / Unmute.
  - `F`: Полноэкранный режим.
  - `S`: Скриншот кадра.
  - `N`: Следующая серия.
- Автоматическое сохранение текущей позиции просмотра каждые 3 секунды.
- Автоматический переход к следующей серии при завершении текущей.

### 5.2. Умный пропуск OP / ED
- Проверка текущего времени `video.currentTime`:
  - Если `op_start <= time <= op_end`: отображается плашка «Смотреть опенинг (5с)». Если пользователь не кликает в течение 5 секунд, плеер перематывает на `op_end`. Если пользователь кликнул — плашка скрывается и продолжается обычный просмотр.
  - Если `ed_start <= time`: отображается кнопка «Следующая серия (5с)», по истечении времени автоматически запускается следующая серия.

## 6. Локальное хранилище и синхронизация (Firebase Ready)

### 6.1. Модель данных (TypeScript интерфейсы)
- `WatchProgress`: `{ animeId, episodeNumber, currentTime, duration, completed, updatedAt }`
- `AnimeListItem`: `{ animeId, title, poster, status: 'watching' | 'planned' | 'completed' | 'dropped', rating, updatedAt }`
- `UserSettings`: `{ uiScale: number, theme: string, activeFrame: string, autoSkipOp: boolean, autoNextEpisode: boolean }`

### 6.2. Сервис данных `StorageService`
- Реализация поверх `localStorage` и IndexedDB.
- Данные сохраняются надежно и восстанавливаются при каждом запуске.
- Интерфейс `IStorageSyncProvider` позволяет при добавлении ключей Firebase переключить локальный репозиторий на Firebase Firestore без изменения интерфейса.

## 7. Платформенные обёртки и сборка

### 7.1. Electron (Windows)
- `electron/main.ts`:
  - Безоконный режим (`frame: false, titleBarStyle: 'hidden'`).
  - IPC-обработчики: минимизация, максимизация, закрытие окна.
  - Проверка обновлений: фоновый запрос к GitHub Releases API (`https://api.github.com/repos/vanaedynak/aniplayer/releases/latest`), сравнение версии с `app.getVersion()`.
  - При наличии новой версии отправка события в рендерер (`update-available`) для показа кнопки «Обновить» в шапке и настройках.
- Сборщик: `electron-builder`:
  - Выходной файл: `AniPlayer-Setup.exe` (NSIS).

### 7.2. Capacitor (iPad)
- `capacitor.config.ts`:
  - `appId: 'com.aniplayer.app'`
  - `appName: 'AniPlayer'`
  - `webDir: 'dist'`
- Плагины:
  - `@capacitor/status-bar`: скрытие строки состояния при полноэкранном просмотре видео.
  - `@capacitor/screen-orientation`: поддержка альбомной и портретной ориентации на планшете.

## 8. GitHub CI/CD Pipeline

Файл `.github/workflows/build-and-release.yml`:
1. **Триггер**: пуш тега `v*.*.*` или ручной запуск `workflow_dispatch`.
2. **Windows Job (`runs-on: windows-latest`)**:
   - Node.js 22+
   - `npm ci`
   - `npm run build`
   - `npm run electron:build`
   - Артефакт: `release/AniPlayer-Setup-*.exe`
3. **iPad Job (`runs-on: macos-14`)**:
   - Установка CocoaPods, Node.js
   - `npm ci && npm run build`
   - `npx cap sync ios`
   - Сборка неподписанного `.xcarchive` через `xcodebuild -workspace ios/App/App.xcworkspace -scheme App -configuration Release CODE_SIGNING_ALLOWED=NO CODE_SIGN_IDENTITY="" CODE_SIGNING_REQUIRED=NO`
   - Экспорт в неподписанный `AniPlayer.ipa` (Payload/App.app -> zip -> .ipa)
   - Артефакт: `ios/AniPlayer.ipa`
4. **Release Job**:
   - Создание GitHub Release с обоими файлами: `AniPlayer-Setup.exe` и `AniPlayer.ipa`.
